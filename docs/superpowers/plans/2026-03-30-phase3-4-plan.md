# Phase 3+4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Add configurable workflow templates, CLI onboarding wizard, monitoring TUI, and Bors-style merge queue.

**Architecture:** Four independent feature streams: (1) Workflow engine refactors the core loop to be step-driven, (2) Init wizard guides first-time setup, (3) Watch TUI provides live monitoring, (4) Merge queue handles automated PR merging with bisection.

**Tech Stack:** TypeScript ESM, ink+react (TUI), better-sqlite3, vitest, zod, execa

**Implementation order:** Workflow engine first (touches core types used everywhere), then merge queue (new module, needs forge additions), then init wizard and TUI (independent leaf features).

## Phase 8: Ops Engines (~70% incomplete)

This is the largest remaining gap. Basic CLI commands exist inline but need extraction to proper engine modules.

### `src/ops/sync.ts` — SyncEngine
Full `reconcile(dryRun): Promise<SyncResult>`:
1. Check all runs with status 'running' — query forge: is issue still open? is PR merged?
2. PR merged -> mark run completed, update labels
3. Issue closed externally -> mark run completed
4. Run status 'running' but lease expired -> check if worker still alive, else mark stale
5. Fix label mismatches (DB says running, forge missing running label)
6. Clean expired leases
7. Detect orphaned worktrees (no matching run)
8. Return structured `SyncResult` with `reconciledRuns`, `expiredLeases`, `orphanedWorktrees`, `labelCorrections`

```typescript
interface SyncResult {
  reconciledRuns: SyncAction[];
  expiredLeases: number;
  orphanedWorktrees: string[];
  labelCorrections: LabelCorrection[];
}

interface SyncAction {
  repo: string;
  issueNumber: number;
  action: 'completed' | 'closed' | 'label_corrected' | 'lease_expired' | 'stale_cleared';
  reason: string;
  prNumber: number | null;
}

interface LabelCorrection {
  repo: string;
  issueNumber: number;
  added: string[];
  removed: string[];
  reason: string;
}
```
